From the command line

The same operations, for scripts and automation
tokenis-mcp keys create analyst@example.com --config tokenis.toml
tokenis-mcp keys revoke KEY_ID --config tokenis.toml

Keys are stored only as SHA-256 hashes; a revocation applies on the next request, on every replica. Principals come from credentials, never from tool arguments.
