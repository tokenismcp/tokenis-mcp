The same operations, for scripts and automation
tokenis-mcp keys create analyst@example.com --config tokenis.toml

Connect an AI app in three steps

Claude, Cursor, VS Code and other MCP apps can ask this gateway directly
  1. Get an API keyAn administrator issues one per person on the Access page. It is shown once.
  2. Pick your app and copy the settingsReplace YOUR_API_KEY with the key. The gateway address is filled in.
  3. Restart the app and askFor example: “Which industry grew most this year?” Answers come from protected statistics only.
This gateway signs callers in with API keys. ChatGPT cannot send an API key: it needs OAuth, so an administrator has to switch the gateway to identity-provider sign-in ([auth] mode = "jwt").

Settings for each app follow its vendor's documentation. The gateway itself is tested with real MCP clients; check the app's own version if something does not connect.

Every person needs their own key: budgets, refusals and the audit trail are kept per key. Never share a key in a chat or a ticket.
