# Tokenis

> Work in progress — scaffold and papers landed, reference SDK and research
> reproduction code are being built out milestone by milestone. See
> [`papers/`](./papers) for the research this project implements.

Tokenis is a cryptographic disclosure-boundary gateway that sits between an
enterprise's protected data and a large language model, exposed to the model as an
MCP (Model Context Protocol) server. A full project README (architecture, quickstart,
benchmark summary) lands in a later commit.
